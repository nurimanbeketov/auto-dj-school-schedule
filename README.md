# auto-dj-school-schedule
Мектеп қоңыраулары мен үзілістегі музыканы автоматты түрде басқаратын жүйе. Кесте бойынша дыбыстық сигналдар мен тректерді адам қатысуынсыз өзі қосады. Система для автоматического управления школьными звонками и музыкой на переменах. Включает треки и сигналы строго по расписанию без участия человека.
